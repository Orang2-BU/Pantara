# UX/UI Specification

## Screen priority

1. Landing / product explanation
2. Team dashboard ★ DEMO CRITICAL
3. Project and task list
4. Create task ★ DEMO CRITICAL
5. Adaptive analysis ★ DEMO CRITICAL
6. Assignment comparison ★ DEMO CRITICAL
7. Employee My Work
8. Capacity signal
9. Task detail / blocker
10. Workload review / redistribution ★ DEMO CRITICAL
11. Work profile and access preferences

## Rules

- Selalu tampilkan “Why this task?” pada assignment.
- Gunakan label capacity, bukan label kesehatan.
- Jangan gunakan warna sebagai satu-satunya pembeda status.
- Hindari leaderboard, ranking, dan angka performa tunggal.
- Sediakan keyboard flow, readable text, clear focus, dan plain-language copy.

## Hero interaction

Saat lead mencoba assign task, tampilkan perubahan workload kandidat sebelum/sesudah, alasan rekomendasi, dan kontrol keputusan manusia.
