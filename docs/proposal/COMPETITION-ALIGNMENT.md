# Competition Alignment

## Positioning

Tema MindCraft: digital solutions for mental well-being. Pantara-MindCraft masuk melalui intervensi pada faktor organisasi yang dapat berkontribusi pada work pressure: workload imbalance dan access friction.

## Rubric mapping

| Area | Bukti yang ditampilkan |
|---|---|
| Innovation & relevance | Tiga engine + capacity-aware recommendation |
| Functionality & fit | Golden demo journey yang benar-benar berjalan |
| UX/UI | Explainable assignment, accessible states, clear navigation |
| Impact | Workload visibility, employee agency, redistribution |
| Presentation | Demo sebelum/sesudah assignment maksimal 7 menit |

## Demo order

1. Tampilkan workload imbalance.
2. Buat task kompleks dengan deadline.
3. Jalankan analysis.
4. Bandingkan kandidat dan alasan.
5. Simulasikan dampak assignment.
6. Konfirmasi keputusan manusia.
7. Kirim capacity signal/blocker.
8. Tampilkan redistribution suggestion.

## Proposal checklist

- Problem dan target user jelas.
- Hubungan well-being tidak overclaim.
- MVP dapat dibuktikan lewat link/demo.
- Accessibility, privacy, dan AI boundaries dijelaskan.
- Semua angka dan klaim eksternal memiliki sumber.
