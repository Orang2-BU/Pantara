# User Journey

## Golden demo journey — Team Lead

1. Buka project.
2. Buat task: skill, complexity, effort, deadline, access requirements.
3. Pilih **Analyze team**.
4. Lihat kandidat, evidence, capacity, access readiness, dan alasan.
5. Bandingkan dampak assignment terhadap workload.
6. Pilih **Assign** atau ubah keputusan.
7. Employee menerima task dan memberi capacity signal.
8. Jika blocker atau workload berubah, lead membuka **Review redistribution**.

## Employee journey

`My work → Task detail → Why this task? → Update progress → Capacity signal → Report blocker → Complete task → Completion context`

## Admin journey

`Workspace → Team → Members → Roles → Workplace support → Access settings`

## Required states

- Empty: belum ada project/task/member.
- Loading: analisis sedang diproses.
- No recommendation: data belum cukup; jelaskan data yang kurang.
- Access unresolved: barrier belum terjawab; jangan labeli employee incapable.
- Error: retry dan fallback ke assignment manual.
- Success: assignment dan dampak workload terkonfirmasi.
