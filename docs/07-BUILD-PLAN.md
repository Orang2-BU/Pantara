# Build Plan

## Pembagian empat orang

| Owner | Deliverable pertama |
|---|---|
| A — Product/engine | Brief, rules engine, recommendation copy |
| B — UX/frontend | Screens, interaction, accessibility |
| C — Backend/data | Schema, API, auth, seed data |
| D — Integration/QA | End-to-end wiring, test cases, demo script |

## Milestones

`M0 docs + seed → M1 workspace/team → M2 project/task → M3 profiles/capacity/access → M4 analysis/recommendation → M5 assignment/employee flow → M6 feedback/redistribution → M7 accessibility/privacy → M8 polish/demo`

## Vertical slice rule

Selesaikan satu alur nyata lebih dulu: create task → analyze → assign → employee signal. Baru tambah fitur pendukung.

## Handoff rule

Setiap fitur selesai jika memiliki UI state, API/data contract, seed/demo data, dan satu cara verifikasi.
